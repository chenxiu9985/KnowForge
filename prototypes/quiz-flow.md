# 主题练习页面原型

```text
KnowForge                                     接口文档

选一个主题，做三道题。

新建练习                     答题区
学习主题 [Python asyncio]    生成后显示题目和选项
[示例主题]                   提交后显示得分和逐题解析
[生成练习]                   [提交答案]
```

| 页面状态 | 学习者能看到和操作的内容 |
| --- | --- |
| 初始 | 输入或选择学习主题，再生成练习。启用真实模型时可以粘贴参考资料。 |
| 出题中 | 生成按钮显示进度，等待结果。 |
| 答题中 | 右侧显示三道单选题，全部作答后可以提交。 |
| 已判分 | 显示分数、正确选项和解释。再次选择主题可开始新一轮。 |
| 出题失败 | 生成区域显示错误，允许修改输入后重试。 |

窄屏下，新建练习和答题区上下排列。运行版页面在 [`frontend/index.html`](../frontend/index.html)。
